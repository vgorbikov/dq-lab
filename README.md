# DQ-lab

Тестовая БД для курса по профилированию и качеству данных.

Структура репозитория:
- `data_samples` - заготовки для генерации правдоподобных данных.
- `entities` - сущности, используемые сервисами предприятия.
- `services` - сервисы предприятия, генерирующие данные.
- `DDL` - скрипты для инициализации схемы базы данных.
- `common_generators.py` - генераторы синтетических данных.
- `write_raw_data.py` - цикл для эмуляции деятельности сервисов, в котором происходит генерация данных и их запись в слой сырых данных хранилища.
