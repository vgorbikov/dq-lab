# DQ-lab

Тестовая БД для курса по профилированию и качеству данных.

Структура репозитория:
- `data_samples` - заготовки для генерации правдоподобных данных.
- `entities` - сущности, используемые сервисами предприятия.
- `services` - сервисы предприятия, генерирующие данные.
- `DDL` - скрипты для инициализации схемы базы данных.
- `common_generators.py` - генераторы синтетических данных.
- `raw_data_translation.py` - функциональность для записи данных сущностей на слой сырых данных.
- `generate_raw_data.py` - цикл для эмуляции деятельности сервисов, в котором происходит генерация данных и их запись в слой сырых данных хранилища.

## Создание тестовой БД

1. Сначала в корне репозитория необходимо создать `.env` файл, содержащий данные для подключения к вашей будущей тестовой БД:
    ```file
    DB_NAME=имя_вашей_БД
    DB_USER=ваше_имя_пользователя
    DB_PASSWORD=ваш_пароль
    DB_HOST=localhost
    DB_PORT=5432
    ```
2. Далее создайте тестовую БД, запустив сборку docker-compose. При создании БД, автоматически выполнятся DDL-запросы для инициализации слоёв хранилища:
    ```bash
    docker compose up
    ```
3. Когда тестовая БД будет запущена, можете сгенерировать данные RAW-слоя, запустив скрипт `generate_raw_data.py`. Количество генерируемых данных и дату начала отсчёта можно указать, изменяя переменные `ITER_COUNT` и `START_TIME` соответственно (за 1к итераций генерируется около 20 Мб данных). Доджитесь окончания генерации.
4. Загрузите таблицы измерений, выполнив sql-скрипты из файла `DML/load_dims.sql` и `DML/load_facts.sql` в указанной последовательности.

Готово!
